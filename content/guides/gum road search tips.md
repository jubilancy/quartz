# gum road search tips

Do you ever find that your Gumroad search is too cluttered to find things, or it doesn't give you good results, or you just want to clean it up?  
  
You can set up [https://imgur.com/SbjHzWD](<https://imgur.com/SbjHzWD>) to do just that.  
  
Step 1.  
[https://imgur.com/ZUe0Ctk](<https://imgur.com/ZUe0Ctk>)  
Type in your search term, search, and then open the tag window.  
  
Step 2.  
[https://imgur.com/nuRaXKP](<https://imgur.com/nuRaXKP>)  
[https://imgur.com/CbqZiRl](<https://imgur.com/CbqZiRl>)  
Tagging is a bit cumbersome, but  
you can set up filters by checking a few (1-3?) boxes to suit what you're looking for  
  
search example :  
[https://gumroad.com/discover?query=Photoshop+actions&sort=curated&tags=photoshop%2Cphotoshop+actions](<https://gumroad.com/discover?query=Photoshop+actions&sort=curated&tags=photoshop%2Cphotoshop+actions>)  
  
It's confusing at first, but once you get used to it, it's a handy feature.  
  
Tip 1. check the price to '0' to get free resources  
  
Tip 2. There is also a star rating search function and a file name search function, but I don't use them.  
  
Tip 3. Browse the another category.  
  
Tip 4. It's good to search in English.  
  
Tip 5. Gumroad changed the search result query URL address, so set it like this.  
For example,  
  
[https://gumroad.com/?query=clip+studio+brushes](<https://gumroad.com/?query=clip+studio+brushes>)  
You can search for this URL as  
[https://gumroad.com/discover?query=clip+studio+brushes](<https://gumroad.com/discover?query=clip+studio+brushes>)  
?query URL with the word 'discover' in front of it,  
  
or  
  
[https://gumroad.com/discover?query=clip+studio+brushes](<https://gumroad.com/discover?query=clip+studio+brushes>)  
search again in Gumroad by '+ delete the word'  
clip+studio+brushes  
clip studio brushes.
